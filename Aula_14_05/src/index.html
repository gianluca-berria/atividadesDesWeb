p7zip é a versão para linha de comando do 7-Zip para Unix/Linux, feito por um desenvolvedor independente.

Alguns pacotes não-oficiais do p7zip para Linux e outros sistemas:

  • p7zip para Debian (e para Ubuntu)
  • p7zip para Fedora Core
  • p7zip para Gentoo
  • p7zip para AltLinux.org
  • p7zip para FreeBSD
  • keka - o compactador livre para Mac OS X
  • p7zip para Amiga
  • p7zip para Solaris
  • p7zip para AIX
